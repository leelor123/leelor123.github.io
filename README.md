# leelor123.github.io

Root site for the **ShiftPay** app (https://leelor123.github.io/shifts/).

`/.well-known/assetlinks.json` links the Android app `io.github.leelor123.shifts` (Google Play) to this
website, so the app opens full-screen without a browser address bar. It lists the SHA-256 fingerprints of
the signing certificates: the upload key, and — after the first Play upload — the Play app-signing key
(Play Console › Test and release › App integrity › App signing).
